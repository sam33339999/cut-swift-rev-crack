## 怎樣算答對

沒有被截斷，而且可見回答最後一個 `ANSWER:` 的整數等於標準答案。截斷留在分母裡，算錯。思考區裡出現過答案不算答對。

難題中位數至少比基線少 15%，而且答對筆數沒有少超過 1，才算這輪達標。差幾個 token 不要寫成成功。
